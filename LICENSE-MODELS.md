## Why the split

The `.scad` files are source code and behave like code — you include them,
derive from them, refactor them — so they take the permissive licence that
code ecosystems expect (MIT, in [LICENSE](LICENSE)).

The STLs are a design. CC BY is what the printing world already reads,
already credits, and already understands, so the models carry that instead.
